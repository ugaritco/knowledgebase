* **Local Path:** [`j:\ugarit\sources\levantc`](file:///j:/ugarit/sources/levantc)
* **Upstream Organization:** `https://github.com/levantc`
* **Inventory of Modules:**
  1. **`levantc`**: Foundational core orchestrating modular services.
  2. **`console`**: Console utilities, components, and CLI helpers.
  3. **`identity`**: User entities, RBAC permissions, and authentication models.
  4. **`i18n`**: Core internationalization, linguistic, and translation logic.
  5. **`i18n-ui`**: Translation management interfaces and switcher components.
  6. **`storage`**: Media library, disk management, and attachment handling.

  9. **`attributes`**: Dynamic custom field attributes (EAV pattern).

  11. **`registry`**: Distributed service and feature registries.
  12. **`versioning`**: Entity audit trails, visual diffs, and revision history.
  13. **`laravel-starter-kit`**: Reference scaffolding templates and starter flows.
  14. **`documentation`**: Architectural reference manuals and API docs.
